# BeamBridge Solar

npm install && npm run dev

- Edit stats, contact details and images in `src/data/site.js`.
- Images are Unsplash placeholders; replace with licensed photos of your own projects.
- The contact form validates client-side; wire `onSubmit` in `src/pages/Contact.jsx` to a backend/form service.
- For hosting, configure SPA fallback so /about and /contact serve index.html.
